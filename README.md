# Finanzas Camilo v1

PWA de finanzas personales para registrar ingresos, gastos, ahorro, presupuesto mensual, deudas y metas.

## Funciones
- Registrar ingresos, gastos y ahorro.
- Registro rápido, por ejemplo: `45000 almuerzo mastercard`.
- Presupuesto mensual.
- Resumen por categorías.
- Deudas.
- Metas de ahorro.
- Exportar movimientos a CSV.
- Exportar/importar respaldo JSON.
- Funciona offline después de la primera carga.

## Privacidad
La app no envía datos financieros a ningún servidor. Los datos se guardan localmente en el navegador mediante `localStorage`.
